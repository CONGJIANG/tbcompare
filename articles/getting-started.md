# Getting Started

``` r

library(xtrial)
```

Let’s start with a simple example: a cross-trial causal comparison
problem where we want to estimate the effect of treatment `a` versus
treatment `b` when the two randomized trials do not share the same
active comparator.

The [xtrial](https://congjiang.github.io/xtrial/) package provides a
common interface for fitting several estimators under different
identification strategies. These include:

- inverse probability weighting (IPW),
- g-computation,
- one-step / efficient influence function (EIF) estimation, and
- targeted minimum loss-based estimation (TMLE).

The package also supports several comparison strategies, including
traditional indirect comparison, observational comparison, direct pooled
IPD comparison, and indirect pooled IPD comparison.

## Simulating Example Data

For illustration, we will use a simulated dataset generated by
[`simulate_xtrial_data()`](https://CONGJIANG.github.io/xtrial/reference/simulate_xtrial_data.md).
The data-generating mechanism is motivated by cross-trial tuberculosis
treatment comparisons.

``` r

dat <- simulate_xtrial_data(
  n = 1000
)

head(dat)
#>   s         L1 L2 country treatment y
#> 1 1 -0.7115241  0       2         a 0
#> 2 1  0.6621788  0       1       sc2 0

#> 5 1 -1.2035661  0       3         a 0
#> 6 2 -1.0398170  0       3       sc1 0
```

The simulated data contain the outcome, treatment assignment, study
indicator, and baseline covariates needed by the estimators in
[xtrial](https://congjiang.github.io/xtrial/).

## A First Analysis

The main user-facing function is
[`xtrial()`](https://CONGJIANG.github.io/xtrial/reference/xtrial.md). A
simple call fits one comparison approach with one estimator.

For example, the following code fits a TMLE estimator using the direct
pooled IPD comparison approach.

``` r

fit <- xtrial(
  data = dat,
  approach = "direct",
  estimator = "tmle",
  nuisance_type = "simple"
)

fit
#> 
#> xtrial object
#> 
#> Estimator: TMLE 
#> Approach : Direct 
#> 
#> Estimate : 0.0140
#> SE       : 0.0488
#> 
#> 95% CI:
#> (-0.0816, 0.1097)
```

Notice what
[`xtrial()`](https://CONGJIANG.github.io/xtrial/reference/xtrial.md)
returns: an object containing the point estimate, standard error,
confidence interval, and information about the fitted approach and
estimator.

We can store the fitted object and summarize it:

``` r

summary(fit)
#>   estimator approach   estimate         se      ci_low  ci_high
#> 1      tmle   direct 0.01400569 0.04879952 -0.08163961 0.109651
```

## Reusing Arguments

When fitting several estimators to the same dataset, it is often helpful
to store repeated arguments first. This keeps the calls short and makes
the analysis easier to read.

## Simple and Flexible Nuisance Estimation

Some estimators require nuisance functions, such as outcome regressions,
treatment mechanisms, or study membership probabilities. The argument
`nuisance_type` controls how these nuisance functions are estimated.

For a fast, reproducible example, we use `nuisance_type = "simple"`
above. When flexible estimation is desired, use:

``` r

fit_flexible <- xtrial(
  data = comparison_data,
  approach = "direct",
  estimator = "tmle",
  nuisance_type = "flexible"
)

fit_flexible
```

Flexible nuisance estimation may be slower, but it can be useful when
the working models used by the simple implementation are too
restrictive.

## A Minimal Workflow

A typical [xtrial](https://congjiang.github.io/xtrial/) workflow is:

1.  prepare or simulate a dataset with the required outcome, treatment,
    study, and covariate variables;
2.  choose an identification approach;
3.  choose an estimator;
4.  call
    [`xtrial()`](https://CONGJIANG.github.io/xtrial/reference/xtrial.md);
    and
5.  inspect the estimate, standard error, and confidence interval.

For example:

``` r

dat <- simulate_xtrial_data(n = 1000)

fit <- xtrial(
  data = dat,
  approach = "direct",
  estimator = "tmle",
  nuisance_type = "simple"
)

summary(fit)
#>   estimator approach   estimate         se      ci_low   ci_high
#> 1      tmle   direct 0.07424915 0.04894494 -0.02168118 0.1701795
```
